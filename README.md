- 🎞️ **Smooth scroll-reveal animations**
- 🪶 **Lightweight:** a single `index.html` with no frameworks and no build step

## 🚀 Run it locally

```bash
git clone https://github.com/abrarxploit/abrarxploit.github.io.git
cd abrarxploit.github.io
# just open index.html in your browser, or:
python3 -m http.server 8000
# then visit http://localhost:8000
```

## 🎛️ Customize

- **Colors:** edit the CSS variables at the top of `index.html` (`--a` and `--b` are the accent colors; each theme has its own set).
- **Content:** every section is plain HTML, so edit the text directly.
- **Resume:** replace `resume.pdf` with a new file of the same name.
